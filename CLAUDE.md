# Claude Entry Point

Siga `AGENTS.md`.

Antes de implementar, trate `docs/sdd/` como fonte de verdade transversal. Para
backend, leia também `api/docs/sdd/`; para frontend, leia também `ui/docs/sdd/`.
Atualize endpoints, rotas, fluxos, contratos e decisões afetados na mesma mudança e
execute os quality gates definidos em `AGENTS.md`. Respeite a natureza histórica
das features: documentos de demandas já entregues nunca devem ser alterados.

Bugfixes diretos: docs vivas na mesma mudança.

Pedidos para criar ou refinar uma feature autorizam somente seu SDD autocontido.
Encerre o trabalho depois de apresentá-lo; implemente e atualize os SDDs vivos
somente após uma ordem explícita do usuário em uma mensagem posterior.
