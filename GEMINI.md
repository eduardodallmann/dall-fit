# Gemini Entry Point

Siga `AGENTS.md`.

Leia primeiro `docs/sdd/README.md` e a base transversal. Depois, conforme o escopo,
leia o SDD da API em `api/docs/sdd/` ou da UI em `ui/docs/sdd/`. O comportamento
vigente e as decisões documentadas devem acompanhar toda implementação. Execute os
quality gates definidos em `AGENTS.md`. Features de demandas já entregues são
registros históricos; mudanças posteriores exigem uma nova feature.

Pedidos para criar ou refinar uma feature autorizam somente seu SDD autocontido.
Encerre o trabalho depois de apresentá-lo; implemente e atualize os SDDs vivos
somente após uma ordem explícita do usuário em uma mensagem posterior.
